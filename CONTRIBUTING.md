# Contributing

Bug reports, documentation corrections, and reproducibility improvements are welcome.

Before opening a pull request:

1. Create a dedicated branch.
2. Keep scientific changes separate from formatting changes.
3. Add or update tests when changing model equations or preprocessing.
4. Run `python -m unittest discover -s tests -v`.
5. Describe whether a change requires recalibration of the model parameters.

Do not commit confidential monitoring records, personal information, reviewer correspondence, or machine-specific paths.
